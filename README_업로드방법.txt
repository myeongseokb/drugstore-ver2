HOWELL 하우웰 | GitHub Pages 슬라이드 수정본
============================================

[1] ZIP 전체 업로드 권장
이 ZIP 압축을 풀면 index.html / style.css / script.js / img 폴더가 바로 보입니다.
GitHub 저장소의 최상위(루트)에 그대로 업로드하세요.
중요: HOWELL_GitHub_슬라이드완성본이라는 폴더 자체를 저장소에 올리지 말고,
폴더 안쪽의 파일들을 선택하여 올리세요. GitHub Pages는 루트 index.html을 읽습니다.

[2] 기존 상품 이미지가 있는 GitHub 저장소를 업데이트한다면
변경분 ZIP만 사용하세요:
- index.html
- style.css
- script.js
- img/hero-1.webp ~ hero-4.webp
기존 img/product-01.webp ~ product-50.webp는 삭제하지 마세요.

[3] 사진·소스 안내
첫 화면에 4장의 실사풍 AI 이미지가 6초 간격으로 교차합니다.
수동 이전/다음 버튼과 슬라이드 선택 점, 위치 카운터(01/04), 하단 진행 표시가 있습니다.
HERO_IMAGE_PROMPTS.txt는 사진을 재생성하기 위한 참고 프롬프트이며, 홈페이지 구동에는 필요하지 않습니다.

[4] 배포
GitHub > 저장소 > Settings > Pages > Deploy from a branch > main / (root) > Save
사이트 새로고침은 Ctrl+Shift+R(Windows) 또는 Cmd+Shift+R(Mac)으로 강력 새로고침.

[5] 주의
체험몰입니다. 회원·주문 데이터는 브라우저 localStorage 기반이고 서버에 저장되지 않습니다.
의약품은 정보용이며 온라인 주문이 불가합니다. 실제 로그인/결제 용도가 아닙니다.
