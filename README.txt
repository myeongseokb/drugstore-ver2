HOWELL 하우웰 — GitHub Pages 체험몰

1. 이 ZIP을 압축 해제합니다.
2. index.html, style.css, script.js, img 폴더를 GitHub 저장소 최상위에 올립니다.
3. 저장소 Settings > Pages > Build and deployment > Deploy from a branch를 선택합니다.
4. Branch는 main, Folder는 /(root)로 지정하고 저장합니다.
5. 안내된 웹사이트 주소에서 쇼핑몰을 엽니다.

중요: 이 프로젝트는 실제 결제를 하지 않는 정적 데모입니다.
회원/포인트/장바구니/주문/재고는 각 브라우저의 localStorage에만 저장됩니다.
데모 회원가입에는 실제 사용하는 이메일과 비밀번호를 입력하지 마세요.
의약품 카테고리는 온라인 주문이 불가능한 정보 안내용입니다.
실제 사업 운영에는 적법한 판매 요건, 서버 인증 및 데이터베이스, 실결제 연동이 필요합니다.

이미지: 4개의 AI 생성 히어로 이미지 + 50개의 자체 제작 상품 일러스트(WebP)
       상품 일러스트 SVG 원본도 img 폴더에 포함했습니다.
